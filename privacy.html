Privacy Policy

Last updated: November 10, 2026

Garmin Cloud Sync is a personal, non-commercial fitness data synchronization tool operated by its account owner.

Data Access

The application is designed to access Garmin activity, HRV, sleep, and Body Battery information with the owner's authorization.

Google Drive

The application uses Google Drive authorization to create and update synchronization files in the account owner's Google Drive.

Data Sharing

The application is not designed to sell personal data or share it with advertisers. Data is processed using GitHub Actions and stored in the owner's Google Drive.

Data Control

The owner can delete synchronized files from Google Drive and revoke application access through Google Account settings.
